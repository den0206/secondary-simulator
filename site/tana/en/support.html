Getting started

  1. Open Folder Settings and choose the data folder for your agent. The usual folders are ~/.claude for Claude Code and ~/.codex for Codex. Press ⌘⇧G in the folder picker to enter a path.
  2. Run a scan and inspect the overview, conversations, and file details.
  3. Select items to clean up, review the details, and move them to the Trash.

A folder cannot be added or read

Select the agent data folder itself, rather than your entire home folder. tana supports real folders on the internal disk; symbolic links and cloud-synced folders are not supported. If a folder moved or its permission expired, select it again in Folder Settings.

Some items cannot be moved

Protected items, in-use items, and items whose use cannot be checked are excluded. Quit the agent and scan again. Select unverified items only after checking their purpose and the effect of removing them. If a cleanup partly fails, review the result and scan again before deciding what to do with the remaining items.

Restoring items from the Trash

Quit the agent first, then open Recently moved in tana. Restore records cover the latest 20 cleanups within 30 days, and the items must still be in the Trash. tana will not overwrite an item already at the original location. If restoration fails, check the Trash in Finder.

tana cannot restore items after the Trash is emptied or the items are permanently deleted. Restoring a file does not guarantee that the agent will list or resume the conversation.

Free disk space has not increased

tana moves items to the Trash; it does not permanently delete them. Sizes shown are logical sizes and may differ from the actual space freed. Emptying the Trash prevents restoration, so check its contents first.

Removing permissions or records

Remove a folder in Folder Settings to revoke tana's saved access to it. This does not delete the agent's original data. Cleanup History and Recently moved have separate controls for clearing their records. Clearing restore records leaves the items in the Trash, but tana can no longer restore them.
