利用規約

作成日・更新日：2026年10月15日

tanaの開発者（以下「提供者」）は、次の条件で本アプリを提供します。

1. 本アプリについて

tanaは、Mac内のClaude Code / Codexのデータを調査し、利用者が選択した項目をゴミ箱へ移動・復元するためのアプリです。利用者は、本規約とプライバシーポリシーを確認のうえ、自分が管理する権限のあるデータを対象に利用してください。

2. 整理する前の確認

会話や関連ファイルを削除すると、Agentで会話を再開できなくなる場合があります。整理する内容と影響を確認し、大切なデータは事前にバックアップしてください。分類や容量は参考情報であり、Agentの更新やファイルの変更によって実態と異なる場合があります。

本アプリは設定・認証情報・データベースなどの保護対象や使用中の項目を移動しないように確認しますが、あらゆる形式や状況での完全な判定を保証するものではありません。未検証の項目を選ぶ場合は、その用途と影響を確認してください。

3. ゴミ箱と復元

tanaは対象のコピーを保持しません。復元記録は直近20回の整理・30日以内が対象で、ゴミ箱に項目が残り、必要なアクセス許可があるなどの条件を満たす場合に復元できます。既存ファイルは上書きしません。ゴミ箱を空にした場合、記録を消去した場合、ファイルが移動・変更された場合などは、tanaから復元できないことがあります。

復元しても、Agentの会話一覧への再表示や再開を保証するものではありません。復元記録の有効期間は、ゴミ箱のファイルの保持期間を保証するものではありません。

4. 禁止事項・第三者のサービス

他者の権利を侵害する利用、不正アクセス、法令に違反する利用を禁止します。Claude Code、Codex、macOS、App Storeなどには、それぞれの提供元の利用条件が適用されます。tanaはClaude Code / Codexの公式アプリではありません。

5. 変更・責任

保守や互換性への対応などにより、機能を変更・停止する場合があります。重要な変更はアプリや公開サイトで案内します。提供者は、情報や判定が常に正確であること、利用者の目的に合うこと、すべてのデータを復元できることを保証しません。提供者の故意・重過失による場合、または法令により免責が認められない場合には、免責は適用されません。

6. お問い合わせ

本規約に関するお問い合わせは、mac.pop@icloud.comへご連絡ください。本規約には日本法を適用します。
