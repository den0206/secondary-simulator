tana · Agent Cleaner

Agentのデータを、
見渡して整理。

Claude Code / Codex がMacに保存するデータを確認し、整理するアプリです。容量や会話を見ながら、不要な項目を選んでゴミ箱へ移動できます。

macOS 26以降 · 日本語・英語対応 · 現在、公開準備中です。

使い方・サポート

どこに容量を使っているか確認

Agent・分類ごとの容量や、日別の分布を表示します。会話のプレビューと関連ファイルの詳細を見ながら、整理する対象を選べます。上限などで一部しか調査できなかった場合は、その範囲を表示します。

対象を確認してからゴミ箱へ

移動前に対象を確認し、使用中の項目や設定・認証情報・データベースなどの保護対象は移動しません。会話や未検証の項目には確認が必要です。会話を削除すると、Agentから再開できなくなる場合があります。

最近移動した項目を元に戻す

復元記録が残り、項目がゴミ箱にある場合は、元の場所へ戻せます。復元記録は直近20回の整理・30日以内が対象です。既存ファイルは上書きしません。ゴミ箱を空にした後は復元できません。

処理はMacの中で

アクセスするAgentフォルダは自分で選択します。ファイルの調査・会話プレビュー・整理はMac内で行い、会話やファイルを開発者やAIサービスへ送信しません。

表示容量はファイルの論理サイズです。ゴミ箱への移動だけでは、同じ量の空き容量が増えるとは限りません。大切なデータは整理前にバックアップしてください。
